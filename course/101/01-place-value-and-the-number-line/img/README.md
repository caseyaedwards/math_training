# Figures

Hand-authored SVG figures for the lesson in the parent folder. Each figure has a generator spec comment above its embed.

* [base-ten-blocks-237.svg](base-ten-blocks-237.svg): Base-ten blocks for 237: two hundreds squares, three tens rods, seven ones cubes.
* [binary-1011.svg](binary-1011.svg): Binary place value for 1011, which equals 11.
* [compare-6190-6099.svg](compare-6190-6099.svg): Comparing 6,190 and 6,099 column by column; the hundreds column decides.
* [distance-23-61.svg](distance-23-61.svg): Number line showing the distance from 23 to 61 is 38.
* [number-line-0-100.svg](number-line-0-100.svg): Number line from 0 to 100 with 37 marked.
* [place-value-columns.svg](place-value-columns.svg): Place value columns for 3,507.
* [rounding-3748.svg](rounding-3748.svg): 3,748 on a number line from 3,700 to 3,800; it is 48 from 3,700 and 52 from 3,800.
* [times-ten-shift.svg](times-ten-shift.svg): Multiplying 470 by 10 shifts each digit one place left to give 4,700.
