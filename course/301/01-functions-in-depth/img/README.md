# Figures

Hand-authored SVG figures for the lesson in the parent folder. Each figure has a generator spec comment above its embed in the lesson.

* [composition-machines.svg](composition-machines.svg): Composition f(g(x)) as two machines in a pipeline.
* [domain-number-line.svg](domain-number-line.svg): Number line showing the domain [3, 5) union (5, infinity): closed dot at 3, open dot at 5, shaded to the right.
* [domain-range.svg](domain-range.svg): Domain and range of f(x) = sqrt(x + 2).
* [horizontal-line-test.svg](horizontal-line-test.svg): Horizontal line test: y = x squared fails on all reals, but passes when restricted to x at least 0.
* [inverse-reflection.svg](inverse-reflection.svg): The function f(x) = x squared for x >= 0 and its inverse sqrt(x), mirror images across y = x.
* [mapping-diagrams.svg](mapping-diagrams.svg): Arrow diagrams: a function can send two inputs to one output, but never one input to two outputs.
* [transformation-stages.svg](transformation-stages.svg): Building y = -2(x + 1)^2 + 3 from y = x^2 in three moves.
* [transformations.svg](transformations.svg): Transformations of y = x squared: shifts on the left, stretch and reflection on the right.
* [vertical-line-test.svg](vertical-line-test.svg): Vertical line test: the parabola passes, the circle fails because one vertical line meets it twice.
