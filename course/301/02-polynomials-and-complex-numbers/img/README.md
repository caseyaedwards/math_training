# Figures

Hand-authored SVG figures for the lesson in the parent folder. Each figure has a generator spec comment above its embed in the lesson.

* [complex-addition.svg](complex-addition.svg): Adding complex numbers like arrows: (2 + i) + (1 + 3i) = 3 + 4i, which has length 5.
* [complex-plane.svg](complex-plane.svg): The complex plane: real part across, imaginary part up.
* [end-behavior.svg](end-behavior.svg): End behavior of four basic leading terms.
* [multiplicity.svg](multiplicity.svg): Near a zero: multiplicity 1 crosses, 2 touches and turns, 3 crosses with a flat wiggle.
* [number-systems.svg](number-systems.svg): Nested number systems: natural numbers inside integers inside rationals inside reals inside complex numbers.
* [polynomial-zeros.svg](polynomial-zeros.svg): The polynomial p(x) = (x + 2)(x − 1)²(x − 3): crosses at −2 and 3, touches at 1.
* [powers-of-i.svg](powers-of-i.svg): Powers of i as quarter turns: 1, i, -1, -i, then back to 1.
* [synthetic-division.svg](synthetic-division.svg): Synthetic division of x^3 - 6x^2 + 11x - 6 by x - 1, showing multiply and add steps.
