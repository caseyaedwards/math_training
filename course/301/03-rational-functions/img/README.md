# Figures

Hand-authored SVG figures for the lesson in the parent folder. Each figure has a generator spec comment above its embed in the lesson.

* [asymptotes.svg](asymptotes.svg): The function f(x) = 1/(x − 2) + 1 with vertical asymptote x = 2 and horizontal asymptote y = 1.
* [hole.svg](hole.svg): The function g(x) = (x² − 1)/(x − 1) is the line y = x + 1 with a hole at (1, 2).
* [horizontal-asymptote-cases.svg](horizontal-asymptote-cases.svg): Three horizontal asymptote cases: bottom degree bigger gives y = 0, equal degrees give the ratio of leading coefficients, top bigger by one gives a slant asymptote.
* [reciprocal.svg](reciprocal.svg): The parent rational function y = 1/x with a table of points: huge near 0, tiny far away.
* [work-rate.svg](work-rate.svg): Work rate: worker A does 1/6 of a job per hour, worker B 1/3; together they finish in 2 hours.
