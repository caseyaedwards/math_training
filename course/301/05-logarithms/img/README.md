# Figures

Hand-authored SVG figures for the lesson in the parent folder. Each figure has a generator spec comment above its embed in the lesson.

* [binary-search-halving.svg](binary-search-halving.svg): Binary search halves 16 candidates to 1 in 4 steps, so log base 2 of 16 is 4.
* [latency-log-scale.svg](latency-log-scale.svg): A log scale of latency from 1 nanosecond to 1 second; each tick is ten times the last.
* [linear-vs-log-axis.svg](linear-vs-log-axis.svg): The same five request rates on a linear axis and on a log axis.
* [log-inverse.svg](log-inverse.svg): The curves y = 2^x and y = log base 2 of x are reflections across y = x.
* [log-question.svg](log-question.svg): Logarithm as a question: log base 2 of 8 asks how many 2s multiply to 8; the answer is 3.
* [powers-of-two-ruler.svg](powers-of-two-ruler.svg): A base-2 ruler of sizes: each step is one more bit, and every 10 bits multiplies the size by 1,024.
* [slide-rule.svg](slide-rule.svg): Slide rule: adding the lengths log 2 and log 3 gives log 6, so 2 times 3 = 6.
