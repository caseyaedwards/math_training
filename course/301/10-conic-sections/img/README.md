# Figures

Hand-authored SVG figures for the lesson in the parent folder. Each figure has a generator spec comment above its embed in the lesson.

* [circle-distance.svg](circle-distance.svg): Circle with center (2, 1) and radius 3: the distance formula from the center to a point P is the Pythagorean theorem.
* [completing-square.svg](completing-square.svg): Completing the square with tiles: x squared plus 6x is a 3 by 3 corner short of the square (x + 3) squared.
* [cone-slices.svg](cone-slices.svg): Side view of a double cone cut by four planes: circle, ellipse, parabola, hyperbola.
* [ellipse-anatomy.svg](ellipse-anatomy.svg): Ellipse anatomy for x^2/25 + y^2/9 = 1: a = 5, b = 3, c = 4, with the right triangle b, c, a.
* [four-conics.svg](four-conics.svg): The four conics drawn from their equations with foci, directrix and asymptotes.
* [parabola-reflector.svg](parabola-reflector.svg): Parabola as a reflector: rays parallel to the axis bounce off y = x squared over 4 and all pass through the focus (0, 1).
