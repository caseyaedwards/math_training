# Figures for Applications of Integrals

Hand-authored SVG figures for the [Applications of Integrals](../README.md) lesson, in the order they appear. Each figure has a generator spec comment above its embed in the lesson.

* [area-between-curves.svg](area-between-curves.svg): Graphs of y equals x and y equals x squared from 0 to 1, crossing at (0, 0) and (1, 1). The region between them is shaded light orange. A darker vertical strip at x equals 0.6 has width dx and height labeled x minus x squared.
* [disk-volume.svg](disk-volume.svg): The curve y equals square root of x from 0 to 4 and its mirror image below the axis, dashed, outline a solid shaped like a rounded horn. Gray ellipses at x equals 1, 2, 3, and 4 show circular cross-sections. An orange disk at x equals 2.5 has radius square root of x and thickness dx.
* [average-value.svg](average-value.svg): The hump of sine x from 0 to pi, shaded light orange. A dashed orange rectangle of height 2 over pi, about 0.637, spans the same interval. The rectangle has the same area, 2, as the hump.
* [avg-rate.svg](avg-rate.svg): A request rate curve over 45 seconds, shaded light orange. A dashed orange rectangle at height 221.2 requests per second spans the same 45 seconds. The total is about 9,955 requests.
* [headroom.svg](headroom.svg): Over a 24-hour day, an orange horizontal line marks capacity at 1,000 requests per second. A load curve rises from 200 at midnight to 800 at noon and falls back. The region between them is shaded and labeled unused headroom.
