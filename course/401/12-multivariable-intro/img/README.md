# Figures for Multivariable Calculus Intro

Hand-authored SVG figures for the [Multivariable Calculus Intro](../README.md) lesson, in the order they appear. Each figure has a generator spec comment above its embed in the lesson.

* [surface-slice.svg](surface-slice.svg): A wireframe dome, the surface z equals 4 minus x squared minus y squared, drawn in 3D with x, y, and z axes. An orange curve runs over the top of the dome where the plane y equals 0 cuts it. A dark tangent line touches the orange curve at x equals 0.75, with slope negative 1.5.
* [contour-gradient.svg](contour-gradient.svg): Nested ellipses for x squared plus 2 y squared equals 1, 2, 4, 6, and 8, with the level-4 ellipse drawn darker. Six orange arrows start on the level-4 ellipse and point outward, each perpendicular to the ellipse.
* [surface-slice-x.svg](surface-slice-x.svg): The same wireframe dome. This time the orange curve runs where the plane x equals 0 cuts it, along the y direction. A dark tangent touches it at y equals negative 1 with slope 2.
* [gradient-descent.svg](gradient-descent.svg): Nested ellipses of x squared plus 4 y squared, stretched sideways. An orange path of arrows starts at (2.6, 1) and zigzags toward the center: each arrow crosses the narrow y direction and overshoots, while creeping steadily along x.
* [double-sum-grid.svg](double-sum-grid.svg): A rectangle from 0 to 3 in x and 0 to 2 in y divided into 24 cells. Each cell shows the value of x plus y at its center, from 0.5 in the bottom left to 4.5 in the top right, with darker orange for larger values. Each cell has area 0.25, and the sum of value times area is 15.
* [iterated-slices.svg](iterated-slices.svg): The rectangle from 0 to 3 by 0 to 2, shaded darker toward the right. One vertical orange slice at x near 1.85, of width dx, is labeled: x plus y summed over y from 0 to 2 equals 2x plus 2. Caption: inner integral along y, then outer integral of 2x plus 2 from 0 to 3 gives 15.
