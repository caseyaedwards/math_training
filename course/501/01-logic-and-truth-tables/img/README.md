# Diagrams: Logic and Truth Tables

Hand-authored SVG figures used by [the lesson](../README.md). Each file has a matching generator spec comment above its embed in the lesson.

* [de-morgan.svg](de-morgan.svg): Four Venn panels: NOT P, NOT Q, their union, and NOT (P AND Q); the last two shade the same region, everything except the overlap.
* [implication-subset.svg](implication-subset.svg): Circle P drawn inside circle Q to show if P then Q; a point in Q outside P shows why the converse fails; a point outside Q is also outside P.
* [logic-venn.svg](logic-venn.svg): Four Venn panels shading where P AND Q, P OR Q, NOT P, and P implies Q are true.
* [quantifier-negation.svg](quantifier-negation.svg): Six host boxes, five with check marks and host5 with a cross; the negation of every host is healthy is some host is not healthy.
* [truth-table.svg](truth-table.svg): Truth table for P and Q with columns AND, OR, implies, XOR; true cells shaded; the single false row of P implies Q outlined.
