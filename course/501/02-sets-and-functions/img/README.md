# Diagrams: Sets and Functions

Hand-authored SVG figures used by [the lesson](../README.md). Each file has a matching generator spec comment above its embed in the lesson.

* [cartesian-grid.svg](cartesian-grid.svg): Grid with rows web1, web2, db1 and columns port 80 and 443; each of the 6 cells holds an ordered pair.
* [composition.svg](composition.svg): Two pipelines: 1 through f (add 2) then g (times 5) gives 15; 1 through g then f gives 7.
* [function-arrows.svg](function-arrows.svg): Three arrow diagrams: a one-to-one map, an onto map, and a relation that is not a function.
* [power-set-tree.svg](power-set-tree.svg): Decision tree: a in or out, b in or out, c in or out, giving 8 leaves from the empty set to {a, b, c}, each with its 3-bit code.
* [set-operations.svg](set-operations.svg): Four Venn panels shading union, intersection, A minus B, and the complement of A.
* [subset.svg](subset.svg): Circle A drawn inside circle B inside the universe U, with the element 3 inside A.
* [venn-regions.svg](venn-regions.svg): Venn diagram: A = {1,2,3,4}, B = {3,4,5,6}, the overlap {3,4} shaded, 7 and 8 outside both.
