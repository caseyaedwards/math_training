# Diagrams: Common Distributions: Binomial, Poisson, Normal, Exponential

Hand-authored SVG figures used by [the lesson](../README.md). Each file has a matching generator spec comment above its embed in the lesson.

* [binomial-paths.svg](binomial-paths.svg): The 8 outcomes of three coin flips arranged in columns for 0, 1, 2, 3 heads, with 1, 3, 3, 1 strings: the binomial coefficients.
* [distributions.svg](distributions.svg): Four panels: binomial n=10 p=0.3 bars peaking at 3, Poisson rate 3 bars, standard normal bell with middle 68 percent shaded, exponential decay with tail beyond 2 shaded.
* [normal-rule.svg](normal-rule.svg): Normal bell curve with bands within 1, 2 and 3 standard deviations of the mean holding 68, 95 and 99.7 percent.
* [poisson-timeline.svg](poisson-timeline.svg): A 10-minute timeline with 15 event dots; the count in each one-minute window is written above; one gap between events is marked below.
* [z-score.svg](z-score.svg): Two aligned number lines: latency from 140 to 260 ms and z from -3 to +3; 240 ms lines up with z = 2.
