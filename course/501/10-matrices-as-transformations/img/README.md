# Diagrams: Matrices as Transformations

Hand-authored SVG figures used by [the lesson](../README.md). Each file has a matching generator spec comment above its embed in the lesson.

* [composition-order.svg](composition-order.svg): Letter F rotated then stretched gives a wide sideways F; stretched then rotated gives a tall sideways F; the results differ.
* [matrix-times-vector.svg](matrix-times-vector.svg): Grid showing 3 times column (2,0) reaching (6,0), then 2 times column (1,1) reaching (8,2), the product of the matrix with (3,2).
* [transform-gallery.svg](transform-gallery.svg): Letter F transformed by four matrices: rotation by 90 degrees, horizontal stretch, reflection, and shear.
* [transform-grid.svg](transform-grid.svg): Left: standard grid with unit square and basis vectors i and j. Right: after matrix [[2,1],[0,1]], i lands on (2,0), j on (1,1), and the square becomes a parallelogram.
