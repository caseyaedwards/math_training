# Diagrams: Solving Systems With Gaussian Elimination

Hand-authored SVG figures used by [the lesson](../README.md). Each file has a matching generator spec comment above its embed in the lesson.

* [echelon-staircase.svg](echelon-staircase.svg): Augmented matrix before and after elimination; after it, pivots 1, -1, 7 lie on the diagonal with zeros below, forming a staircase.
* [elimination-lines.svg](elimination-lines.svg): Left: lines x + y = 3 and x - y = 1 cross at (2,1). Right: after subtracting row 1 from row 2 the second line becomes horizontal y = 1, still crossing at (2,1).
* [systems-cases.svg](systems-cases.svg): Three panels of two lines: crossing at (2,1) for one solution, parallel for no solution, and the same line for infinitely many solutions.
