# Diagrams: Eigenvalues and Eigenvectors

Hand-authored SVG figures used by [the lesson](../README.md). Each file has a matching generator spec comment above its embed in the lesson.

* [char-poly.svg](char-poly.svg): Parabola lambda squared minus 4 lambda plus 3 crossing the horizontal axis at lambda = 1 and lambda = 3.
* [circle-ellipse.svg](circle-ellipse.svg): Unit circle mapped by [[2,1],[1,2]] to an ellipse whose long axis (length 3) and short axis (length 1) lie along the eigenvectors.
* [eigen-directions.svg](eigen-directions.svg): Matrix [[2,1],[1,2]] stretches (1,1) to (3,3) along the same line, keeps (1,-1) fixed, and turns (1,0) to (2,1) off its line.
* [markov-updown.svg](markov-updown.svg): State diagram: UP stays up with 0.9 and goes down with 0.1; DOWN recovers with 0.5 and stays down with 0.5; the steady state is 5/6 up, 1/6 down.
* [power-iteration.svg](power-iteration.svg): Unit-length arrows for v, Av, A squared v, A cubed v, A to the fourth v at angles 0, 26.6, 38.7, 42.9 and 44.3 degrees, closing in on the 45 degree eigen-direction.
