# Figures

Hand-authored SVG figures for [this lesson](../README.md). Each one is embedded in the lesson with a generator spec comment above it.

* [consecutive-three.svg](consecutive-three.svg): Three consecutive integers level out to three equal columns.
* [divides-chain.svg](divides-chain.svg): If 2 divides 6 and 6 divides 18 then 2 divides 18.
* [even-odd-dots.svg](even-odd-dots.svg): Even and odd numbers as rows of dots.
* [odd-square.svg](odd-square.svg): An odd square is an even part plus one corner.
