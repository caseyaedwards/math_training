# Figures

Hand-authored SVG figures for [this lesson](../README.md). Each one is embedded in the lesson with a generator spec comment above it.

* [cases-even-odd.svg](cases-even-odd.svg): Neighbors on the number line always include an even number.
* [contrapositive-venn.svg](contrapositive-venn.svg): P inside Q: P implies Q, and not Q implies not P.
* [iff-arrows.svg](iff-arrows.svg): If and only if is two arrows.
* [triangle-inequality.svg](triangle-inequality.svg): The triangle inequality on the number line.
