# Figures

Hand-authored SVG figures for [this lesson](../README.md). Each one is embedded in the lesson with a generator spec comment above it.

* [bezout-lattice.svg](bezout-lattice.svg): Values of 6x plus 9y are exactly the multiples of 3.
* [common-divisors.svg](common-divisors.svg): The pairs 24, 9 and 9, 6 share the same common divisors.
* [divides-hops.svg](divides-hops.svg): Multiples of 6 as hops on a number line.
* [division-algorithm.svg](division-algorithm.svg): The division algorithm as hops plus a remainder.
* [euclid-bars.svg](euclid-bars.svg): Euclidean algorithm remainders as shrinking bars.
* [euclid-rectangle.svg](euclid-rectangle.svg): Euclid algorithm as tiling a rectangle with squares.
