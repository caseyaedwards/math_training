* [residue-classes.svg](residue-classes.svg): Integers sorted into three rows by remainder mod 3.
* [times-2-mod-6.svg](times-2-mod-6.svg): Multiplication by 2 mod 6 is not a shuffle.
* [times-3-mod-7.svg](times-3-mod-7.svg): Multiplication by 3 permutes the nonzero residues mod 7.
