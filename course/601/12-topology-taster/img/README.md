# Figures

Hand-authored SVG figures for [this lesson](../README.md). Each one is embedded in the lesson with a generator spec comment above it.

* [euler-characteristic.svg](euler-characteristic.svg): Euler characteristic of a tetrahedron, cube and torus.
* [genus.svg](genus.svg): Sphere, torus and double torus with their Euler characteristics.
* [letter-holes.svg](letter-holes.svg): Letters sorted by number of holes.
* [mug-to-donut.svg](mug-to-donut.svg): A coffee mug deforms into a donut.
* [nested-open-intervals.svg](nested-open-intervals.svg): Open intervals shrinking to one point.
* [open-set.svg](open-set.svg): An open interval versus a closed interval.
* [preimage.svg](preimage.svg): Preimages of an open window under a continuous map and a jump.
* [stretch-map.svg](stretch-map.svg): A homeomorphism from an open interval onto the real line.
