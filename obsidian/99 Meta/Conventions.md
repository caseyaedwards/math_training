# Conventions

- **Status:** `not-started`, `in-progress`, `review`, `done`, `parked`.
- **Confidence (0-5):** 0 never seen · 1 recognise it · 2 can follow a worked example ·
  3 can solve standard problems · 4 can solve unfamiliar problems · 5 can teach it.
- **Spaced review:** after a session set `next_review` to +1 day, then +3, +7, +21, +60
  each time you review it without trouble. Drop back to +1 if you struggled.
- **Links to material:** point at the repo on GitHub, e.g.
  `[Lesson](https://github.com/caseyaedwards/math_training/tree/main/course/101)`.
  Paths are placeholders until that content lands; fix them as it does.
- **Diagrams:** embed SVGs from the generator with `![[file.svg]]` after copying them
  into `50 Resources/attachments/`, or link to the showcase on GitHub.
- **Math:** Obsidian renders LaTeX: inline `$a^2+b^2=c^2$`, block `$$\int_0^1 x\,dx$$`.
- **Tags:** `#stuck`, `#aha`, `#revisit`, `#proof`, `#visual`.
