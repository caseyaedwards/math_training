# Tracks

A track is a roadmap through one field of math, from the first idea to the advanced material.
The course moves through many fields at once. A track stays in one field and goes deep.

Each track has a concept map, a beginner-to-advanced concept ladder, the big theorems, a starter problem set, and classic resources.
