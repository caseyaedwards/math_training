# Abstract Algebra Code

Companion program for the [Abstract Algebra Track](../README.md). It uses the Go standard library only.

[main.go](main.go) checks the group axioms by brute force, lists element orders and generators of $\mathbb{Z}/12$, composes triangle symmetries in both orders, counts necklaces with Burnside, and runs a toy Diffie-Hellman key exchange. Run it with `go run main.go` in this folder.

```txt
go run main.go
```

The expected output is printed in the Code Corner section of the [track README](../README.md#code-corner).
