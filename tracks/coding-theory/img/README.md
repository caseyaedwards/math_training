# Coding Theory Diagrams

Hand-authored SVG diagrams for the [Coding Theory Track](../README.md), listed in the order they appear:

* [concept-map.svg](concept-map.svg): Coding Theory Concept Map.
* [decoding-spheres.svg](decoding-spheres.svg): Codewords far apart with non-overlapping decoding balls.
* [repetition-majority.svg](repetition-majority.svg): Repetition code with majority vote and its error rate.
* [parity-bit.svg](parity-bit.svg): Even parity bit catches one flip and misses two.
* [isbn-checksum.svg](isbn-checksum.svg): ISBN-10 weighted checksum catches a swap that a plain sum misses.
* [hamming-cube.svg](hamming-cube.svg): Three-bit words on a cube with codewords 000 and 111.
* [generator-matrix.svg](generator-matrix.svg): Encoding data 1101 with the Hamming 7,4 generator matrix.
* [syndrome-decoding.svg](syndrome-decoding.svg): Parity check matrix H whose columns count 1 to 7 in binary.
* [sphere-packing.svg](sphere-packing.svg): All 128 seven-bit words split into 16 balls of 8.
* [crc-long-division.svg](crc-long-division.svg): CRC long division of 110101 by 1011 over GF(2).
* [gf7-table.svg](gf7-table.svg): Multiplication table mod 7 with inverse pairs marked.
* [reed-solomon-line.svg](reed-solomon-line.svg): Reed-Solomon idea: two points fix a line, extra points are spares.
* [raid5-rebuild.svg](raid5-rebuild.svg): RAID 5 stripe with XOR parity and a rebuild after one disk dies.
* [storage-tradeoff.svg](storage-tradeoff.svg): Storage overhead versus losses survived for six schemes.
* [tanner-peeling.svg](tanner-peeling.svg): Tanner graph of a small erasure code decoded by peeling.
* [fountain-extra.svg](fountain-extra.svg): Extra symbols a random linear fountain needs beyond k.
