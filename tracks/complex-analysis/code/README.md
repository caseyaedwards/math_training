# Complex Analysis Code

Companion program for the [Complex Analysis Track](../README.md). It uses the Go standard library only.

[main.go](main.go) uses Go's built-in `complex128` type and `math/cmplx` to rotate by $i$, check the polar rule and Euler's formula, list roots of unity, sum the power series, compute contour integrals numerically, and print a small Mandelbrot set. Run it with `go run main.go` in this folder.

```txt
go run main.go
```

The expected output is printed in the Code Corner section of the [track README](../README.md#code-corner).
