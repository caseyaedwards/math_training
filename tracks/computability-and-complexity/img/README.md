# Computability and Complexity Diagrams

Hand-authored SVG diagrams for the [Computability and Complexity Track](../README.md), listed in the order they appear:

* [concept-map.svg](concept-map.svg): Computability and Complexity Concept Map.
* [map-of-problems.svg](map-of-problems.svg): Nested classes of problems from regular to undecidable.
* [decision-problem-box.svg](decision-problem-box.svg): A decision problem sorts strings into yes and no.

* [regex-nfa-dfa.svg](regex-nfa-dfa.svg): NFA and DFA for the regular expression (a|b)*abb.
* [redos-backtracking.svg](redos-backtracking.svg): Backtracking steps versus DFA steps for (a+)+b.
* [pumping-loop.svg](pumping-loop.svg): Pumping argument for a^n b^n.
* [pda-stack.svg](pda-stack.svg): Stack contents while checking (()()).

* [machine-ladder.svg](machine-ladder.svg): Finite automaton, pushdown automaton and Turing machine side by side.
* [halting-diagonal.svg](halting-diagonal.svg): Diagonal table behind the halting problem.
* [halting-paradox.svg](halting-paradox.svg): The program D built from a supposed halting decider.
* [reduction-halt-to-config.svg](reduction-halt-to-config.svg): Reduction from halting to a config safety question.
* [growth-curves.svg](growth-curves.svg): Growth of n, n log n, n squared and 2 to the n.
* [find-vs-check.svg](find-vs-check.svg): Subset sum, finding versus checking.
* [p-np-two-worlds.svg](p-np-two-worlds.svg): The two possible worlds for P and NP.
* [sat-to-independent-set.svg](sat-to-independent-set.svg): Reduction from 3-SAT to independent set.
* [vertex-cover-approx.svg](vertex-cover-approx.svg): Vertex cover by matching versus the optimum.
* [scheduling-greedy-vs-optimal.svg](scheduling-greedy-vs-optimal.svg): Greedy longest-first schedule versus optimal.
