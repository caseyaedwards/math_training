# Differential Equations Code

Companion program for the [Differential Equations Track](../README.md). It uses the Go standard library only.

[main.go](main.go) compares the Euler method with the fourth-order Runge-Kutta method (RK4), checks the logistic solution, cools a server, drains a queue and classifies three springs. Run it with `go run main.go` in this folder.

```txt
go run main.go
```

The expected output is printed in the Code Corner section of the [track README](../README.md#code-corner).
