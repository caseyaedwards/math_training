# Functional Analysis Diagrams

Hand-authored SVG diagrams for the [Functional Analysis Track](../README.md), listed in the order they appear:

* [concept-map.svg](concept-map.svg): Functional Analysis Concept Map.
* [function-vector-analogy.svg](function-vector-analogy.svg): A vector and a function, each split into coordinates along an orthogonal basis.
* [function-as-vector.svg](function-as-vector.svg): A function sampled at a few points is a list of numbers, a vector.
* [function-addition.svg](function-addition.svg): Functions add point by point, like vectors add coordinate by coordinate.
* [unit-balls.svg](unit-balls.svg): Unit balls of the L1, L2 and sup norms in the plane.
* [function-norms.svg](function-norms.svg): Three norms of f(x) = x on 0 to 1.
* [xn-convergence.svg](xn-convergence.svg): X to the n: the L2 norm shrinks to 0 while the sup norm stays 1.
* [sin-cos-orthogonal.svg](sin-cos-orthogonal.svg): The product sin x cos x has equal positive and negative area, and the inner product is 0.
* [cauchy-step.svg](cauchy-step.svg): Continuous ramps converge in L2 to a step function that is not continuous.
* [projection.svg](projection.svg): Projection onto a line gives the closest point, and Fourier partial sums are projections.
* [parallelogram-law.svg](parallelogram-law.svg): The parallelogram law holds for the L2 norm and fails for the sup norm.
* [operator-stretch.svg](operator-stretch.svg): A shear maps the unit circle to an ellipse; the operator norm is the longest stretch.
* [derivative-unbounded.svg](derivative-unbounded.svg): Sin(nx) keeps the same size while its derivative grows n times.
* [riesz-levelsets.svg](riesz-levelsets.svg): A linear functional's level sets are parallel lines perpendicular to one vector g.
* [spectral-axes.svg](spectral-axes.svg): A symmetric matrix stretches along perpendicular eigenvector axes.
* [spectral-modes.svg](spectral-modes.svg): Eigenfunctions of minus the second derivative on 0 to 1 with fixed ends.
* [quantum-projections.svg](quantum-projections.svg): A quantum state as a unit vector; squared coordinates give measurement probabilities.
* [kernel-lift.svg](kernel-lift.svg): Points on a line that one cut cannot separate become separable after lifting to x and x squared.
