* [tit-for-tat-rounds.svg](tit-for-tat-rounds.svg): Tit-for-tat copies the last move of the opponent.
* [tournament-scores.svg](tournament-scores.svg): Round-robin tournament scores from the code.
* [braess-paradox.svg](braess-paradox.svg): Braess paradox before and after a free shortcut.
* [second-price-payoff.svg](second-price-payoff.svg): Second-price payoff for a bidder with value 70.
* [auction-revenue.svg](auction-revenue.svg): Bids and expected revenue for three auction designs.
