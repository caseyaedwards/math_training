# Linear Algebra Code

Companion program for the [Linear Algebra Track](../README.md). It uses the Go standard library only.

[main.go](main.go) adds vectors, measures angles and projections, applies matrices, computes determinants, solves systems by Gaussian elimination, finds the top eigenvalue by power iteration, ranks three web pages and fits a least squares line. Run it with `go run main.go` in this folder.

```txt
go run main.go
```

The expected output is printed in the Code Corner section of the [track README](../README.md#code-corner).
