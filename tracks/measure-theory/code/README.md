# Measure Theory Code

Companion program for the [Measure Theory Track](../README.md). It uses the Go standard library only.

[main.go](main.go) sorts coins, compares vertical and horizontal slicing for the integral of x squared, climbs simple functions up to the integral, covers the rationals, builds the Cantor set, shows the escaping bump next to a dominated sequence, and estimates probabilities by throwing darts. Run it with `go run main.go` in this folder.

```txt
go run main.go
```

The expected output is printed in the Code Corner section of the [track README](../README.md#code-corner).
