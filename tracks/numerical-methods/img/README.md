# Numerical Methods Diagrams

Hand-authored SVG diagrams for the [Numerical Methods Track](../README.md), listed in the order they appear:

* [concept-map.svg](concept-map.svg): Numerical Methods Concept Map.
* [newton-method.svg](newton-method.svg): Newton method on f(x) = x squared minus 2.
* [float64-bit-layout.svg](float64-bit-layout.svg): Bit layout of a 64-bit IEEE 754 double.
* [toy-float-number-line.svg](toy-float-number-line.svg): Toy floating point numbers become sparser as they grow.
* [point-three-neighbors.svg](point-three-neighbors.svg): Zoomed number line near 0.3 showing neighboring doubles.
* [cancellation-plot.svg](cancellation-plot.svg): Naive formula for (1 - cos x)/x^2 breaks down for small x.
* [bisection-steps.svg](bisection-steps.svg): Bisection halves the bracket around the root of x squared minus 2.
* [convergence-bisection-vs-newton.svg](convergence-bisection-vs-newton.svg): Error per iteration for bisection versus Newton on the square root of 2.
* [trapezoid-rule.svg](trapezoid-rule.svg): Trapezoid rule with four strips under x squared on 0 to 2.
* [lu-factorization.svg](lu-factorization.svg): LU factorization of a 3 by 3 matrix.
* [gradient-descent-zigzag.svg](gradient-descent-zigzag.svg): Gradient descent zigzags across a narrow valley.
* [euler-vs-rk4.svg](euler-vs-rk4.svg): Euler and RK4 compared with the exact solution of y' = y.
* [euler-stability.svg](euler-stability.svg): Euler method on y' = -10y is stable for small steps and blows up for large ones.
