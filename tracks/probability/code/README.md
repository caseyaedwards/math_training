# Probability Code

Companion program for the [Probability Track](../README.md). It uses the Go standard library only.

[main.go](main.go) puts exact answers next to simulations: dice, Monty Hall, the birthday problem, Bayes, redundancy, retries, the UP/DOWN Markov chain and Poisson arrivals. The random seed is fixed, which makes the output repeatable. Run it with `go run main.go` in this folder.

```txt
go run main.go
```

The expected output is printed in the Code Corner section of the [track README](../README.md#code-corner).
