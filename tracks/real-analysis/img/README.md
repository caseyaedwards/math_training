# Real Analysis Diagrams

Hand-authored SVG diagrams for the [Real Analysis Track](../README.md), listed in the order they appear:

* [concept-map.svg](concept-map.svg): Real Analysis Concept Map.
* [epsilon-band.svg](epsilon-band.svg): Sequence 1 plus minus 1 over n entering an epsilon band.
* [completeness-sqrt2.svg](completeness-sqrt2.svg): Rational numbers 1, 1.4, 1.41, 1.414 approach the square root of 2.
* [sequence-one-over-n.svg](sequence-one-over-n.svg): Terms of 1 over n piling up near zero on a number line.
* [geometric-series-square.svg](geometric-series-square.svg): A unit square divided into halves, quarters, eighths showing 1/2 + 1/4 + ... = 1.
* [epsilon-delta-box.svg](epsilon-delta-box.svg): Epsilon delta picture of continuity.
* [mean-value-theorem.svg](mean-value-theorem.svg): Mean value theorem: tangent parallel to secant.
* [riemann-lower-upper.svg](riemann-lower-upper.svg): Lower and upper Riemann sums for x squared on 0 to 1 with five strips.
* [x-to-the-n.svg](x-to-the-n.svg): Graphs of x to the n on 0 to 1 for growing n.
* [unit-balls-three-metrics.svg](unit-balls-three-metrics.svg): Unit balls in the taxicab, Euclidean and max metrics.
* [riemann-vs-lebesgue.svg](riemann-vs-lebesgue.svg): Riemann slices vertically, Lebesgue slices horizontally.
* [fourier-square-wave.svg](fourier-square-wave.svg): Fourier partial sums approaching a square wave.
