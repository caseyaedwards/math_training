# Statistics Code

Companion program for the [Statistics Track](../README.md). It uses the Go standard library only.

[main.go](main.go) computes center and spread, percentiles of 5,000 simulated latencies, z-scores, a confidence interval, the regression line from the diagram, an EWMA anomaly detector, and a bootstrap interval for p99. Run it with `go run main.go` in this folder.

```txt
go run main.go
```

The expected output is printed in the Code Corner section of the [track README](../README.md#code-corner).
